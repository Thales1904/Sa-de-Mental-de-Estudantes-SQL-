# Análise de Saúde Mental de Estudantes Internacionais com SQL

## Sobre o projeto

Este projeto utiliza **SQL** para explorar dados relacionados à saúde mental de estudantes internacionais.

Os dados foram coletados por uma universidade internacional no Japão em 2018 e utilizados em um estudo publicado no ano seguinte. A pesquisa investigou fatores relacionados à saúde mental de estudantes que estavam realizando seus estudos em outro país.

O estudo indicou que estudantes internacionais podem apresentar maior risco de enfrentar dificuldades relacionadas à saúde mental, especialmente quando possuem menor conexão social e maiores níveis de estresse aculturativo.

Neste projeto, os dados da tabela `students` são explorados para analisar a relação entre o **tempo de permanência no país**, a **conexão social**, o **estresse aculturativo** e indicadores relacionados à **depressão**.

---

## Objetivo

Utilizar consultas SQL para investigar se:

* O tempo de permanência no país pode estar relacionado à saúde mental dos estudantes internacionais.
* Estudantes com diferentes períodos de permanência apresentam diferenças nos indicadores analisados.
* Os resultados encontrados apresentam uma tendência semelhante à identificada no estudo original.

---

## Tecnologias utilizadas
